# 真实尺寸参考

这些数字是**量出来的量级**，不是标准条文。卫星图上判断街区时够用，
出施工图当然要查当地规范。澳洲（ACT/NSW）和中国大陆都在这一档。

## 停车

| 项 | 值 | 说明 |
|---|---|---|
| 垂直车位宽 | **250 cm** | 一排车位数车位总宽 ÷ 个数，最可靠的标尺 |
| 垂直车位深 | **525 cm** | 含车头前 30cm 余量；纯车长 450~490 |
| 平行车位长 | 600~660 cm | |
| 无障碍车位宽 | 350~380 cm | 比普通宽一半 |
| 小车 | 长 430~470 × 宽 160~180 | 建模用 430×160 就够 |

**一排 n 个车位的总长 ≈ n × 250 cm**，这条在卫星图上量特别稳：
车与车之间的白线、车身之间的空隙都会告诉你 n。

## 道路

| 项 | 值 | 说明 |
|---|---|---|
| 双向两车道（各一） | **700 cm** | 有中心虚线时，虚线两侧各 350 |
| 双向四车道 | 1300~1400 cm | |
| 单车道（单行） | 350~400 cm | |
| 住宅区人行道 | **250 cm** | |
| 商业区人行道 | 400~600 cm | |
| 路缘石宽 | **15~20 cm** | 平面图上近乎一条线，但渲染必须有 |
| 路缘石高 | 12~15 cm | |
| 车道中心虚线段长 | 240~300 cm，间隔 600~900 cm | |

⚠️ 宽街（单向两车道以上）常在 1000~1100 cm。看到「马路比楼还宽」时先别怀疑画错，
先量一下是不是宽街 —— 澳洲很多次干道就是这个宽度。

## 用这些数字的正确姿势

1. **先量一个，再推全部**。车位宽最好用（数量多、边界清楚）。
2. **至少交叉验证一次**：车位宽算出的比例 vs 楼宽算出的比例，差 > 5% 就说明有一处量错了。
3. **注意透视**。卫星图是正射的，但如果是从街景/无人机斜拍截的，远处会被压缩，
   同一段距离在不同位置量出来不一样 —— 这种图只能量画面中心附近的。
4. **图上带标注的截图要当心**：Google Maps 的 POI 标签会盖住地面，被盖住的地方量不准。
